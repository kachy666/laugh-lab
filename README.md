> The sock had notes of laundry detergent and despair, but I gave it two stars because it kept screaming all the way down.

A one-liner entry for the One-Liner Laugh Lab: a deadpan product review of a sock that treats laundry day like a wine tasting and a horror movie at the same time. The script validates the line — single line, no stray whitespace or control characters, under 200 characters — then writes it to the output file.

## Run it

```sh
python3 main.py
```
